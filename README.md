# WhatsApp Rust Bot — Linux x86_64

نسخة تشغيل جاهزة للبوت لمعمارية **Linux x86_64**.

## التشغيل

1. حمّل `whatsapp-rust-bot-linux-x86_64.zip` وفك ضغطه.
2. انسخ `.env.example` إلى `.env`.
3. ضع رقم WhatsApp الدولي في `WHATSAPP_PHONE_NUMBER`.
4. ضع ملف `cookies.txt` بصيغة Netscape بجانب الملف التنفيذي؛ سيكتشفه البوت تلقائيًا. أو حدّد مسارًا مخصصًا عبر `YTDLP_COOKIES_PATH`.
5. شغّل `./run.sh` أو `./start.sh`.

الحزمة تتضمن Deno x86_64، وتمرر إعداداته إلى استخراج معلومات الفيديو والتنزيل لحل تحديات YouTube JavaScript. لا تحتاج إلى تثبيت Deno على الخادم. الحزمة مخصصة لـ Linux x86_64 فقط. ملف الكوكيز غير مضمن لحماية جلسة الحساب، ولا توجد ملفات Release؛ الحزمة مرفوعة كملف عادي داخل المستودع.
